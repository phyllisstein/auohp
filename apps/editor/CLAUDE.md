This file extends [the main repo's](../../CLAUDE.md). All of the main
`CLAUDE.md` guidelines still apply here. For `@auohp/editor` specifically, you
should also note that comments **must not** use shout-cased words for emphasis.
In this package, Claude and its agents habitually osmose that style from the
Lexical sources when writing comments. It's ticcy and irritating, and typically
a sign that Claude is straying from the "no editorializing in code comments"
rule.
